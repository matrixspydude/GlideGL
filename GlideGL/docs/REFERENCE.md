\# Glide Reference Documentation



A curated list of publicly available documentation used to understand historical graphics

behavior from 1986–2000. These references guide the design of Glide.api. No copyrighted

manuals are included; only links to legal public sources.



\---



\## DOS Graphics (1986–1994)

\- FreeVGA: https://www.osdev.org/FreeVGA

\- OSDev VGA: https://wiki.osdev.org/VGA

\- OSDev Mode X: https://wiki.osdev.org/Mode\_X

\- VESA VBE: https://wiki.osdev.org/VESA\_BIOS\_Extensions

\- Abrash Black Book: https://github.com/jagregory/abrash-black-book

\- PCGPE: https://github.com/Tronche/pcgpe



\---



\## Windows 95 Graphics (1995–1997)
