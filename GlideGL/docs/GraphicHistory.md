\# GRAPHICS HISTORY (1986–2000)



A technical timeline of PC graphics evolution from VGA to early 3D acceleration.



This document outlines the major graphics technologies, APIs, and hardware innovations

from 1986 to 2000, with links to publicly available documentation sources. These references

guide the design of Glide.api, ensuring accurate retro behavior and historically faithful rendering.



...



\## How This Timeline Connects to Glide



Glide.api aims to unify the behavior of these eras:



1986 → VGA  

1990 → Mode X  

1992 → Wolf3D-style engines  

1993 → Doom-style engines  

1994 → SVGA + palette tricks  

1995 → Windows 95 + GDI/WinG  

1996 → DirectDraw  

1996 → Glide  

1997–1999 → Fixed-function 3D pipelines  

2000 → Optional DX8/9 expansion



Glide.api 0.1–0.5 focuses on:

\- DOS

\- Windows 95

\- DirectDraw

\- Glide

\- OpenGL 1.x

\- Vulkan abstraction



DirectX 8/9 are optional for Glide 2.0.
