\# Glide Roadmap



\## Version 0.1 (Current)

\- Project structure established

\- Public Glide.api header created

\- Basic initialization/shutdown

\- Surface loading stub

\- Blitting stub

\- Palette stub

\- Frame presentation stub



\## Version 0.2

\- Implement surface loader

\- Implement software framebuffer

\- Implement blitting

\- Implement palette operations

\- Add basic examples



\## Version 0.3

\- Add retro timing simulation

\- Add scanline simulation

\- Add compatibility tests

\- Add DOS/Win95 behavior notes



\## Version 0.4

\- Begin platform abstraction layer

\- Add window creation

\- Add input handling

\- Add timing system



\## Version 0.5

\- Begin hardware research notes

\- Define 3Dfx prototype hardware interface

\- Early hardware API draft



\---



\## Long-Term Vision

Glide.api becomes the official rendering API for future 3Dfx hardware, powered by the GlideGL backend.
