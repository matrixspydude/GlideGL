# Contributing to Glide (3Dfx Glide Interactive)

Thank you for your interest in helping build Glide.api — the official graphics API of the revived
3Dfx Glide Interactive project.

Glide.api focuses on retro‑correct graphics for DOS and Windows 95 games, and contributions of all
kinds are welcome.

---

## How to Contribute

1. Fork the repository.
2. Clone your fork:
   git clone https://github.com/<yourname>/Glide.git
3. Create a branch:
   git checkout -b feature-name
4. Make your changes.
5. Submit a pull request and describe what you changed and why.

---

## Coding Guidelines

- Use clear, readable C or C++.
- Keep functions small and focused.
- Document behavior related to DOS/Win95 authenticity.
- Avoid unnecessary dependencies.
- Follow the structure in `include/` and `src/`.

---

## Communication

Open an Issue on GitHub to discuss ideas, bugs, or features.  
Thank you for helping build the future of 3Dfx Glide Interactive.
