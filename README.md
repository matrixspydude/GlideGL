# GlideGL — Open-Source 3Dfx Glide API Reimplementation

GlideGL is a clean-room, open-source reimplementation of the 3Dfx Glide API.
This project aims to preserve retro graphics behavior while providing a modern Vulkan backend.

## Current Status
This repository contains the early project structure:
- include/ — API headers
- src/ — core engine code
- docs/ — technical documentation
- examples/ — sample usage (future)
- test/ — unit tests (future)
